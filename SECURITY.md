# Security Policy

## Scope

Simple ATM Simulation is a demo application. It has no database, network
connection, real accounts, or real credentials. The hardcoded demo PINs and the
PIN displayed on the admin screen are intentional parts of the simulation and
are not security vulnerabilities.

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability
reporting:

https://github.com/ShahabAhmed01/Simple-ATM-Simulation/security/advisories/new

If that link is unavailable, open a minimal public issue asking for a private
channel. Do not include exploit details, personal data, or credentials in a
public issue.

Please include:

- A description of the issue and its impact
- Steps to reproduce
- The compiler and operating system you used
- Any suggested fix

This is a volunteer project, so a response may take a few days. Please do not
disclose the issue publicly before it has been addressed.

## Supported versions

There are no released versions yet. Reports are accepted against the latest
commit on `main`.
